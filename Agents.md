
# AGENTS.md

## Project Overview
Build an Employee Support Ticket Management System.
Employees submit IT support tickets and track their progress.
Support staff manage tickets and update their status.

## Technology Stack
- Frontend: React with Vite
- Backend: Python FastAPI
- Database: SQLite
- Styling: Bootstrap
- Backend testing: Pytest

## Project Rules
1. Read the relevant specification before implementing a feature.
2. Do not implement features outside the approved scope.
3. Do not make assumptions about unclear business rules.
4. Keep frontend, backend, database and business logic separated.
5. Use reusable components and functions.
6. Validate all user input on the backend.
7. Enforce role-based authorization on the backend.
8. Never rely only on frontend checks for security.
9. Do not hardcode passwords, API keys or secrets.
10. Do not introduce dependencies without explaining why.
11. Do not modify unrelated files.
12. Add tests for every important business rule.

## Before Implementing
1. Read this file and the relevant specification.
2. Inspect the existing code and architecture.
3. Identify the files that need to change.
4. Explain the implementation approach.
5. Wait for approval when a plan is requested.
6. Implement only the approved task.
7. Run relevant tests and report actual results.

## Code Quality
- Use clear names and consistent formatting.
- Handle errors explicitly.
- Keep functions focused.
- Avoid unnecessary abstractions.
- Keep documentation and tests updated.

## Definition of Done
- Acceptance criteria are satisfied.
- Relevant tests pass.
- Authorization and validation are checked.
- No secrets are committed.
- No unrelated files are changed.
- The implementation is documented.
